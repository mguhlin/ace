HOW THE SCORE WORKS

Six criteria. Four ratings. One practical next step.

Each applicable criterion receives zero to three points. The score is the earned points divided by the possible points, multiplied by 100 and rounded. Articulate uses four criteria, Connect uses five, and Extend uses six. Compare scores only within the same scope and depth.

RatingWhat it means
0 · Not documentedThe document does not show the practice.
1 · IntroducedThe practice appears, but the learning action is limited or unclear.
2 · DesignedThe document describes a usable learning action.
3 · IntegratedThe learning action, reasoning, and instructional response work together.

Interpretation bands: 0–24, Start with the goal; 25–49, Add learning actions; 50–74, Strengthen the connections; 75–100, Refine and try it. These are planning labels, not grades.

For a syllabus, use course outcomes, assessment descriptions, and feedback procedures as evidence. A procedure described once may apply across the course. If details live in an omitted lesson or assessment guide, report them as not documented here; do not infer that the teacher never uses them.

SOLO and ACE inform the target depth. Feedback, metacognitive instruction, and transfer inform the instructional criteria. Effect sizes are not rubric weights.
